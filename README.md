## Projeto em destaque

### Zabbix Monitor TV

O [Zabbix Monitor TV](https://github.com/matheusoliveirait/zabbix-monitor-tv) é um painel web criado para exibir incidentes do Zabbix em TVs e telas de NOC.

O projeto surgiu de uma necessidade real: permitir que a equipe de suporte acompanhe rapidamente os problemas ativos e suas severidades, sem precisar manter a interface completa do Zabbix ou do Grafana aberta na televisão.

O painel consulta diretamente a API do Zabbix e foi desenvolvido para ser simples de instalar, configurar e manter em exibição contínua.
